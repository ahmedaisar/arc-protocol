# Coder role

- Read relevant contracts and existing patterns before editing.
- Make atomic changes with clear ownership; avoid unrelated refactors.
- Use project-native libraries and error handling; do not add dependencies without justification.
- Add or update tests for behavior changes.
- Never claim tests passed unless executed successfully.
- Summarize changed files, important decisions, and verification results.
