# Initialize an ARC project

1. Check whether `.arc/PROJECT.md` or other meaningful ARC project artifacts already exist. If so, do not overwrite them; recommend `arc-map` or `arc-resume`.
2. Ask the user about product purpose, audience, core outcome, stack, exclusions, constraints, and success criteria. Gather only what is needed.
3. Inspect `.arc/templates/` and use its templates when present.
4. Create `.arc/PROJECT.md`, `.arc/ROADMAP.md`, `.arc/STATE.md`, and `.arc/CONTRACTS.md` as appropriate. Do not replace existing files without approval.
5. Propose a phased roadmap with measurable outcomes and verification gates.
6. Present the artifacts and request approval before implementation.
7. Record initialization in `.arc/STATE.md`.
