# Pause work

1. Inspect current changes and active plan.
2. Read PROJECT, STATE, CONTRACTS, and roadmap context relevant to the active phase.
3. Update STATE with completed tasks, in-progress work, uncommitted changes, verification evidence, blockers, and the next safe action.
4. Do not mark incomplete tasks as done or move active plans into an archive.
5. Preserve all working-tree changes. Do not commit, stash, reset, or clean unless explicitly requested.
6. Summarize how to resume with `arc-resume`.
