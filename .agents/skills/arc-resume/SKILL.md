# Resume work

1. Read PROJECT, STATE, ROADMAP, CONTRACTS, active plan/context/summary, and CODEBASE map when available.
2. Inspect git status and recent diffs before continuing; do not overwrite uncommitted changes.
3. Identify last verified milestone, incomplete task, blockers, and decisions still in force.
4. Reconcile written state with repository evidence and call out discrepancies.
5. Propose the smallest safe next step and continue only within the user's authorization.
