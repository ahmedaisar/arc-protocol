# Report status

1. Read `.arc/PROJECT.md`, `.arc/STATE.md`, `.arc/ROADMAP.md`, and active planning artifacts when present.
2. Compare documented status against the repository state where practical.
3. Report completed, in-progress, blocked, and upcoming work separately.
4. Identify stale or contradictory state rather than silently reconciling it.
5. Recommend one concrete next action. Do not modify project files unless asked.
