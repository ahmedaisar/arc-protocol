# Quick task

1. Confirm the task is bounded and does not require broad architectural decisions. If not, use `arc-discuss` and `arc-plan`.
2. Read the relevant project context and contracts.
3. Inspect target files and nearby tests before editing.
4. Make the smallest coherent change; avoid unrelated refactors.
5. Run relevant tests or checks and report exact results.
6. Update STATE and CONTRACTS when warranted.
