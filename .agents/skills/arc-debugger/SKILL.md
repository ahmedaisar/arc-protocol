# Debugger role

1. Reproduce the issue and capture exact symptoms.
2. Trace the relevant execution path and inspect recent changes.
3. Form hypotheses and test them one at a time.
4. Identify root cause, not merely the visible symptom.
5. Propose or implement the smallest safe fix according to task scope.
6. Add a regression test and report evidence.
