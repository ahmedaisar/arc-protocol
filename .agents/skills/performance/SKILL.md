# Application performance

- Establish a measurable baseline and identify the user-visible bottleneck.
- Inspect network, rendering, hydration, CPU, memory, caching, and data-fetching paths as relevant.
- Prefer framework-supported performance patterns over aesthetic micro-optimizations.
- Treat visual styling recommendations as secondary to measured performance goals.
- Check accessibility and perceived performance as well as raw timings.
- Re-measure and report changes with test environment and limitations.
