# Add a roadmap phase

1. Read PROJECT, ROADMAP, CONTRACTS, STATE, and CODEBASE context when available.
2. Clarify the objective and why it belongs in the roadmap.
3. Identify dependencies, sequencing constraints, risks, and measurable outcomes.
4. Add the phase using the existing roadmap format; do not renumber or rewrite completed phases without approval.
5. Create phase context or plan artifacts only when requested.
6. Summarize the change and ask for confirmation before treating the phase as approved work.
