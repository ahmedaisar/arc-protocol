# Discuss a phase

1. Read PROJECT, ROADMAP, CONTRACTS, STATE, and relevant CODEBASE context where available.
2. Explain the phase outcome and identify decisions that materially affect implementation.
3. Ask focused questions grouped around UX, API, data, integrations, operations, security, and edge cases as relevant.
4. Do not ask questions already answered in project artifacts.
5. Save confirmed decisions, rationale, constraints, references, and open questions to `.arc/planning/phase-[N]-CONTEXT.md`.
6. Separate confirmed decisions from assumptions. Do not begin implementation.
