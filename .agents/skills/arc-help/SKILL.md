# ARC help

1. Read the Skills catalog README and repository README when available.
2. Determine whether the user needs installation help, a workflow recommendation, an explanation of project artifacts, or troubleshooting.
3. Explain the smallest useful set of Skills and tools for their goal.
4. Distinguish required protocol capabilities from optional dashboard and MCP integrations.
5. Do not claim a host supports automatic Skills discovery or delegation without checking its documented capabilities.
